# Typography

Typography carries information, hierarchy, and voice. Improve it inside the established visual world.

## Font Choice

Pick a face with a point of view.

Paid, worth it:
- GT Sectra
- Sohne
- ABC Diatype
- Basel Grotesk
- Untitled Sans
- GT Alpina
- Lyon Text
- Berkeley Mono
- Departure Mono

Free, with a fingerprint:
- Instrument Serif
- Fraunces (specific subjects only)
- Newsreader
- Redaction
- Chillax
- EB Garamond
- Source Serif 4

Banned as display face:
- Inter
- Roboto
- DM Sans
- Poppins
- Montserrat
- Space Grotesk
- Outfit
- Plus Jakarta Sans

## Scale

Pick ONE scale and commit:

- Dramatic: 1.5 ratio (16, 24, 36, 54, 81)
- Tight: 1.15 ratio (16, 18, 21, 24)
- Mixed: display 4x+ body, body tight internally

Never: 0.875rem, 0.9375rem, 0.9375em — off-by-half values signal indecision.

## Line Height

- Body: 1.5-1.75 (tune to the face)
- Display: 0.95-1.1
- UI labels: 1.3-1.4

Wider measure needs more line height. Narrow measure can go tighter.

## Measure

- Long-form prose: 60-75 characters
- UI copy: 40-60 characters
- Data: whatever fits without breaking the grid

## Weight

- One family, two weights, three at most
- Weight-inversion is allowed: hero lighter than section head
- Never use weight 900 as a default

## Tracking

- Display: -0.01em to -0.03em
- Body: 0
- Small caps / labels: +0.05em to +0.15em
